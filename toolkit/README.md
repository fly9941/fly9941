# Electrical / E&I Site Toolkit

Blank templates for daily progress and QA/QC tracking. These templates contain no project records or personal documents.

- `dpr-template.csv`: quantities, manpower and constraints by activity. Units must be consistent per activity; planned and completed quantities are daily values, not cumulative totals.
- `inspection-register-template.csv`: inspection, punch and closeout tracking. Acceptance criteria and procedure revisions must come from approved project documents.

Use a private project workspace for populated records. Never store passport, visa, bank information, credentials or confidential project drawings in this public repository. CSV files open in Excel; preserve tag numbers as text and use ISO dates (YYYY-MM-DD).

## Daily workflow
1. Confirm approved drawings, workfront access, permits and required isolation/LOTO with the authorized site team before assigning work.
2. Record actual manpower, installed quantity and constraints.
3. Reconcile progress against the approved scope and units.
4. Record inspection requests and punch items; close only with accepted evidence.
5. Assign the next action, responsible person and due date in the private working copy.

This toolkit does not define electrical test settings or acceptance limits. Follow approved procedures, equipment-specific manufacturer instructions and site safety requirements.
