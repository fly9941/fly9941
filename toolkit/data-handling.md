# Handling work data

Keep filled registers and job applications in a private workspace. This public folder should contain blank templates only.

- Keep API secrets out of source files, CSVs, commits and screenshots. Use the hosting provider's runtime secret store when an integration is implemented.
- Git ignore rules prevent accidental addition of matching untracked files; they do not remove already committed material.
- Export backups before bulk edits. Check imports and compare record counts before replacing data.
- Treat job leads as unverified until the original source and current availability have been checked. Keep exact source URLs and verification dates in the private record.
- Account security settings and private repository creation are not changed by these templates.
